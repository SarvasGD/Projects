# Архивный каталог roach-arcade

Эта папка больше не является источником актуальной игровой сборки.

**Текущая игра:** файл `../roach-rush.html` в корне папки «Тараканьи бега», сборка 261103-1936.

Файл `index.html` в этой папке — ранняя резервная копия примерно на 53 КБ. Не использовать его для разработки и публикации.

Прежнее описание 16 частей, каталога parts/, build.sh и tests/ устарело и не соответствует текущей структуре GitHub. Этих элементов в актуальном каталоге нет; создавать их только ради соответствия старому README не требуется.

Документы пока сохранены в `docs/`:
- `Матрица-разработки.md` — единственная актуальная сводная матрица функций, этапов, статусов и исполнителей.
- `02_ГЕЙМДИЗАЙН.md` — GDD.
- `01_ПРОДЮСЕРСКИЙ_ПИТЧ.md` — продуктовая концепция и коммерческое направление.
- `03_АРТ-ДИРЕКШН.md` — визуальные требования.

См. корневой `../README.md` и `../Мета/Реестр-проекта.md`. Все старые файлы сохранены до отдельного решения об очистке.
