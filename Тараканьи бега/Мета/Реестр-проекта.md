# Реестр проекта «Тараканьи бега» / Roach Rush

Обновлено: 25.11.2026  
Назначение: инвентаризация GitHub-папки, фиксация назначения и актуальности каждого файла. Реестр обновляется при добавлении, переносе, переименовании или выводе файлов из использования.

## Статусы

- **Канонический / активный** — текущий рабочий источник или документ.
- **Актуальный документ** — используется по своему назначению.
- **Устаревший / справочный** — оставлен для истории, не использовать как источник текущей версии.
- **Резервная копия** — сохранённый старый вариант.
- **Ожидает проверки** — содержимое или назначение ещё не установлено.
- **Кандидат на удаление** — предварительная оценка; файл не удалён и не должен удаляться без отдельного решения.

В этой ревизии ничего не удалялось и не перемещалось. Сначала зафиксированы фактическое состояние и назначение, затем можно отдельно принять решение об очистке.

## Папка roach-arcade

Папка исторически называлась рабочим каталогом игры, но сейчас не является источником актуальной сборки. Её содержимое сохранено до завершения инвентаризации и возможной миграции документов.

| Путь | Статус | Назначение |
|---|---|---|
| `roach-arcade/README.md` | Устаревший / перенаправление | Ранее описывал модульную сборку из 16 частей, parts/, build.sh и tests/. Это описание не соответствует текущему проекту; теперь файл указывает на корневой README |
| `roach-arcade/index.html` | Резервная копия; кандидат на удаление | Старый HTML примерно 53 КБ. Не использовать для разработки или публикации. Сохранить до отдельного подтверждения, что резервная копия больше не нужна |
| `roach-arcade/get-fresh-game.html` | Устаревший / справочный | Временная утилита скачивания игры из live-preview песочницы. Не нужна для получения текущей версии из GitHub |
| `roach-arcade/КАК_ПОЛУЧИТЬ_СВЕЖУЮ_СБОРКУ.md` | Устаревший / справочный | Инструкция для старого процесса с live-preview и контрольной суммой. Не считать текущей инструкцией разработки |
| `roach-arcade/_probe.txt` | Временный тестовый артефакт; кандидат на удаление | Файл содержит метку probe-2026-11-04. Похоже на пробу записи/проверку инструментария; не участвует в игре |
| `roach-arcade/t2.txt` | Временный тестовый артефакт; кандидат на удаление | Файл содержит WRITEFILE_TEST. Это тестовый файл записи, не часть игры |

## Важные расхождения, учтённые в реестре

1. Текущая игра — корневой `roach-rush.html`, а не `roach-arcade/index.html`.
2. Описанная в прежнем README структура из 16 исходных частей, `build.sh` и `tests/` в текущем GitHub-каталоге отсутствует и не является действующим требованием.
3. В актуальной сборке 32 записи UPGRADES; обе RU/EN подсказки меню синхронизированы с числом 32.
4. QA основного прототипа выполнен Agent-Qwen в десктоп-чате и принят владельцем. Не трактовать отсутствие его тестовых артефактов в GitHub как невыполненный QA.
5. В текущем HTML публичного репозитория исходный клиентский код доступен для скачивания. Для защиты будущих версий нужно перенести дальнейшую разработку в приватный репозиторий и публиковать отдельно собранный игровой артефакт. Это ещё не сделано.

## Правило обновления реестра

При любом изменении структуры:
- добавить новый файл или папку с назначением и статусом;
- обновить запись при изменении назначения или актуальности;
- при переносе зафиксировать новый путь и прежний путь;
- не удалять файлы до проверки назначения и отдельного решения владельца;
- не заводить отдельную таблицу учёта файлов — этот реестр является единственным источником.
