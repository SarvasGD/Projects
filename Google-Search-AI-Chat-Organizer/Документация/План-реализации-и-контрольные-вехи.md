- Стабильная identity истории: подтверждена на реальной странице Google — 20/20 строк имеют `data-thread-id` на вложенной кнопке; внешний элемент строки — `div[role=listitem]` с полным заголовком.
- v0.4.1 нормализует строку к внешнему listitem, читает ID с вложенной кнопки и проксирует на неё открытие.
- q-only и generic clickable rows не становятся подтверждёнными диалогами.
- URL identity ограничена Google `/search?mtid=...`; неподтверждённые query/hash aliases не используются.
- Сканер накапливает ID через виртуализированные страницы и не скрывает Google history при incomplete/unknown scan.
- Открытая стабильная сессия получает локальную запись даже при первом открытии по явному DOM ID.
- Фильтр All / 2+ / 1 / Not calculated; user-turn count считается по role markers либо transcript markers внутри AI Mode Conversation.
- Старые title-only записи сохраняются, но скрываются и не перепривязываются по названию.
- Автоматические проверки: 26/26 jsdom; Playwright Chromium загружает само MV3-расширение и проверяет identity, user-turn count, фильтр, sync, collapse/restore и q-only fallback.

## Остаток Prototype Gate

**Подтверждено:** identity и структура history rows на живой странице Google.

**Ещё требуется:** один контрольный снимок открытой многоходовой AI Mode-сессии в актуальной v0.4.1. Он должен подтвердить фактические DOM role/message markers, ID текущей сессии и число user turns. Предыдущий снимок истории сделан на v0.3.2 и не содержит структуры сообщений открытого диалога; повторять снимок списка истории не нужно.

Для снимка: открыть существующий диалог с несколькими сообщениями пользователя → открыть диагностическую панель расширения → нажать «Снимок DOM» → прислать скопированный результат. Снимок скрывает текст сообщений и значения ID, но показывает структуру, имена атрибутов, распознанный источник ID и count.

| 5 | Закрытая бета | Recovery, безопасное native delete, большие истории, browser matrix | ID safety, retry, recovery, browser matrix | Один сводный контроль |
| 6 | Soft Launch | Упаковка, onboarding, документация, поддержка | Install/update/performance/browser tests | Приёмка релизного кандидата |

## Gate criteria

- **Prototype Gate:** live history identity подтверждена; q-only не становится чатом; в открытой сессии подтверждены user/assistant markers и user-turn count; unknown/partial уступает место Google; тесты проходят.
- **MVP Gate:** полная доступная история, importer/count, фильтр, папки/перемещение, поиск, Markdown и внешняя sync; нет известных ложных чатов, дублей и потери папок.
- **Closed Beta Gate:** native delete, Resume/retry, recovery и browser matrix проходят крайние случаи.
- **Soft Launch Gate:** установка, обновление, документация, onboarding и производительность готовы.

## Границы прототипа

Полный импорт всей истории с progress/Resume/retry, подсчёт старых/неоткрытых сессий, полная динамическая синхронизация больших историй и нативное удаление не являются блокерами завершения технического прототипа. Это дальнейшая реализация MVP/Closed Beta по функциональной дорожной карте.
