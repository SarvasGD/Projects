## План

| № | **Действие** | Выходной результат | Автоматическая проверка | Участие пользователя |
|---:|---|---|---|---|
| 1 | **Собрать эталонные DOM fixtures сообщений** | Одноходовая сессия, многоходовый диалог, AI-ответы/источники, неизвестные строки | Проверка структуры и отсутствия приватного текста | Один сводный snapshot, если в проекте нет достаточных образцов |
| 2 | **Реализовать classifier и счётчик user turns** | Различие 1, 2+ и unknown; title-only fallback исключён | Unit + fixture tests | Не нужен для каждого патча |
| 3 | **Реализовать фильтр реплик** | UI и настройки порога | Все режимы, граничные случаи, роли сообщений | Апрув UX на Prototype gate |
| 4 | **Реализовать Google synchronizer** | Внешние добавление, переименование, продолжение и удаление отражаются автоматически | Mock/storage integration, partial-load safety, folder binding | Не нужен для обычных регрессий |
| 5 | **Собрать MVP** | Подтверждённые диалоги, папки, перемещение, поиск, Markdown, sync | Полный CI + Playwright fixture suite + migration regression | Один общий MVP acceptance |
| 6 | **Закрытая бета: импорт и нативное удаление** | Resume/retry, безопасный Google Delete, recovery | Synthetic menu tests, ID safety, retry and rollback | Один контроль на реальном аккаунте |
| 7 | **Подготовить Soft Launch** | Упакованная сборка, onboarding, документация и совместимость | Install/update/browser/performance tests | Приёмка релизного кандидата |

## Gate-критерии

- **Prototype gate:** реальные DOM fixtures показывают различие одиночного и многоходового AI Mode; user turns считаются; ID устойчивы; overlay безопасно возвращает оригинал; классификатор не принимает неизвестное за чат.
- **MVP gate:** готов повседневный сценарий — синхронизированный список, фильтр, папки/перемещение, поиск, Markdown и сохранение метаданных.
- **Closed Beta gate:** синхронизация, импорт/Resume, удаление и восстановление проходят крайние случаи на ограниченных реальных аккаунтах.
- **Soft Launch gate:** установка, обновление, документация, производительность и поддерживаемые браузеры готовы для ограниченного публичного использования.

## Первый шаг рабочего цикла
**Исследовать DOM сообщений, не менять production-эвристику.** Получить/собрать обезличенную структуру одноходовой и многоходовой сессии; выявить контейнеры сообщений, role/data-атрибуты и ID; закрепить реальные признаки в fixtures и тестах; только после этого менять classifier.
