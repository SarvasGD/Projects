- v0.3.2 в main — прежняя база; title-only fallback признан ошибочным.
- v0.4.0 считает строку диалогом только при стабильном thread/session ID или URL с thread identity.
- q-only и generic clickable rows не становятся подтверждёнными чатами.
- Счётчик user turns работает по role markers или transcript markers внутри AI Mode Conversation.
- Фильтр All / 2+ / 1 / Not calculated, сохранение режима.
- Старые title-only записи не удаляются, но скрываются; по названию не перепривязываются.
- При unknown/partial load родная история остаётся доступной; старые записи не помечаются удалёнными.
- CI: Manifest V3, JS syntax и 21/21 DOM smoke tests passed. Это synthetic fixtures, не доказательство живого Google DOM.

## Текущий блокер Prototype Gate
Реальные признаки Google DOM ещё не подтверждены на живой странице. Fixtures основаны на известных публичных реализациях AI Mode importers: thread/session identity, mtid/hash thread, role markers и transcript markers. Соответствие текущему UI Google должно быть доказано на одном контрольном прогоне.

## План

| № | **Действие** | Результат | Автопроверка | Участие пользователя |
|---:|---|---|---|---|
| 1 | **Закрыть Prototype Gate по текущему DOM** | Обезличенные fixtures native history row и открытой многоходовой сессии; подтверждены ID и message markers | Fixture suite, parser tests, overlay fallback, partial-load regression | Один объединённый browser checkpoint после внутренних проверок |
| 2 | **Доработать importer всей истории** | Прогресс, сохранение состояния, Resume/retry; count для доступных сессий или причина недоступности | Interrupted/resume/retry, protected current session, unavailable chat tests | Один MVP checkpoint, не каждая сессия |
| 3 | **Довести Google synchronizer** | Внешние add/rename/continue/delete автоматически отражаются | Reconciliation tests для complete/partial load, SPA, delayed rows, folder bindings | Не нужен для рутинных регрессий |
| 4 | **Собрать MVP** | Полный список, фильтр, папки/перемещение, поиск, Markdown, sync | Full CI + DOM/Playwright fixtures + migration regression | Один общий MVP acceptance |
| 5 | **Закрытая бета** | Безопасное штатное удаление, recovery, большие истории, browser matrix | Synthetic menu tests, ID safety, retry, recovery, browser matrix | Один сводный контроль |
| 6 | **Soft Launch** | Упаковка, onboarding, документация, поддержка | Install/update/performance/browser tests | Приёмка релизного кандидата |

## Gate criteria

- **Prototype Gate:** живые DOM fixtures подтверждают identity и роли; одноходовый запрос не становится чатом; user turns считаются; overlay уступает место Google при unknown/partial; тесты проходят.
- **MVP Gate:** полная доступная история, импорт и count, фильтр, папки/перемещение, поиск, Markdown и внешняя sync; нет известных ложных диалогов/дублей/потери папок.
- **Closed Beta Gate:** native delete, Resume/retry, recovery и browser matrix проходят крайние случаи.
- **Soft Launch Gate:** установка, обновление, документация, onboarding и производительность готовы.
