## 2. Fixtures v0.4.0
21 тест покрывает:
- Явные data-thread-id / data-session-thread-id.
- URL identity через mtid и hash thread.
- Отказ от q + udm без thread identity.
- Отказ от generic clickable rows.
- Подсчёт user-role markers с исключением AI responses.
- Transcript markers только внутри AI Mode Conversation.
- Различение 1 user turn / 2+ / unknown.
- Фильтр single/multi/unknown и сохранение режима.
- Overlay только при полном стабильном сканировании; fallback к Google при unknown.
- Lazy loading, сохранение legacy title-only данных без показа в active list.
- Миграция URL к stable ID с сохранением folder/index.
- Запрет rebinding по названию и folder assignment по title-only key.
- Точный click proxy по ID.
- Anonymized DOM snapshot без текста сообщений.
- Сохранение count при чтении сессии.
- Partial/unclassified scan не помечает старые диалоги удалёнными.
- Teardown.

## 3. Developer-first testing

| Уровень | Проверки | Исполнитель |
|---|---|---|
| Статика | Manifest, syntax, permissions, scripts | CI |
| Unit | ID/URL, classifier, count, filters, migration | Автоматически |
| DOM fixtures | Google history, one-shot/multi-turn, AI responses/sources | Автоматически |
| Integration | Lazy loading, MutationObserver, overlay, sync, restore | Playwright после создания harness |
| Data regression | Дубли, потери индекса, folder bindings, ложное удаление | Автоматически |
| Реальный аккаунт | Только то, что не доказать fixtures | Один сводный Prototype Gate |
| Полный продуктовый сценарий | MVP и Closed Beta | Один сводный acceptance на веху |

Не просить пользователя тестировать каждый CSS-патч, кнопку, commit или PR. Разработчик воспроизводит дефект, создаёт fixture, добавляет regression test, исправляет и запускает полный suite.
