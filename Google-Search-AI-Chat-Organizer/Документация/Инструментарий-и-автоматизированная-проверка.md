## Регрессии v0.4.1

- Короткий `mtid=123` принимается, если находится на Google `/search`.
- Q-only и неподтверждённые aliases `tid`, `thread`, hash не принимаются как identity.
- Virtualized scrolling заменяет старые DOM-строки новыми; suite проверяет накопление всех уникальных ID между проходами.
- Завершение lazy loading требует восьми стабильных проходов; изменения native history инвалидируют snapshot.
- DOM snapshot перечисляет имена data-атрибутов и URL-параметров без значений и не содержит тексты сообщений/поисковых запросов.


## Живой DOM, подтверждённый 26.11.2026

Снимок пользователя версии 0.3.2 показывает 20 строк истории; у всех 20 ID определён по `data-thread-id`. ID расположен на вложенном `button`, внешний `div[role=listitem]` содержит полный заголовок. В v0.4.1 сканер нормализует строку к внешнему listitem, читает ID с вложенной кнопки и передаёт на неё click. Эта структура добавлена в jsdom и Playwright regressions.

Не подтверждены реальные user/assistant markers внутри открытой сессии. Для этого нужен один обезличенный «Снимок DOM» из актуальной v0.4.1 на открытом многоходовом диалоге. Текущий снимок истории не требует повторного сбора.
