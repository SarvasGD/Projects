# 01. Постановка задач

**Срез:** 22.11.2026

## 1. Цель продукта

Создать расширение Chromium для Google Search AI Mode, которое организует именно полноценные AI Mode-диалоги в иерархические папки, заменяет штатный список истории в левой панели, поддерживает фильтрацию/поиск и автоматически отражает изменения Google.

## 2. Требования, подтверждённые пользователем

| Требование | Статус | Критерий |
|---|---|---|
| **Органайзер заменяет штатный список истории** | ✅ Подтверждено поведением в браузере | Overlay занимает область истории; второй штатный список не показывается поверх/под ним. Сворачивание возвращает оригинальный список. |
| **Google является источником истины** | ✅ Прямо подтверждено | Состав, названия и состояние диалогов берутся из Google. |
| **Автоматическая синхронизация** | ✅ Прямо подтверждено | Если пользователь добавил, переименовал или удалил диалог непосредственно в Google, органайзер сам отражает это при следующей синхронизации. Не требуется отдельное ручное удаление/добавление в органайзере. |
| **Иерархические папки до 4 уровней** | ✅ Требование проекта | Диалоги перемещаются по папкам без обязательного открытия каждого чата. Создание трёх уровней пользователь проверял; полная приёмка и DnD ещё не завершены. |
| **Только Markdown-экспорт** | ✅ Прямое указание пользователя | Оставить .md; TXT не нужен и удалён. |
| **Без облачного хранилища расширения** | ✅ Базовое архитектурное требование проекта | Папки и локальные индексы хранятся в браузере; Google остаётся источником истории. |

## 3. Функции и критерии, ожидающие пользовательского апрува

| Предложение | Статус | Что требуется подтвердить |
|---|---|---|
| **Фильтр по числу реплик пользователя** | 🟡 На апрув пользователя | Предлагаемый основной критерий: 1 реплика пользователя vs 2+; дополнительно — настраиваемый порог. |
| **Удаление диалога из Google прямо из органайзера** | 🟡 На апрув пользователя | Команда вызывает штатное меню Google для однозначно найденной строки; подтверждает действие и автоматически синхронизирует результат. |
| **Группа «Не классифицировано»** | 🟡 На апрув пользователя | Неизвестные строки не смешиваются с подтверждёнными чатами, пока не рассчитан тип/счётчик. |
| **Архив локально проиндексированного текста после удаления из Google** | 🟡 На апрув пользователя | Нужно решить, сохранять ли кэш содержимого после удаления исходной переписки в Google. Это не должно создавать отдельную обязательную операцию удаления. |
| **Последовательный импорт/подсчёт всех сессий с прогрессом и Resume** | 🟡 На апрув пользователя | LLMnesia показывает полезный сценарий Resume/retry. Нужно выбрать, разрешать ли органайзеру открывать сессии для подсчёта сообщений в отдельной рабочей вкладке/режиме. |

## 4. Запрещённые / отвергнутые подходы

| Подход | Статус | Причина |
|---|---|---|
| **Обязательное локальное удаление после удаления в Google** | ⛔ Не использовать | Пользователь отверг двойное удаление. Google — источник истины; органайзер должен автоматически синхронизировать состояние. |
| **Классификация чата только по названию или кликабельности** | ⛔ Не использовать | Именно это привело к импорту одиночных запросов и мусорных строк. |
| **Скрытие оригинальной истории до полной загрузки/проверки overlay** | ⛔ Не использовать | Риск потерять видимый доступ к штатному списку и показать неполную историю. |
| **TXT-экспорт** | ⛔ Не использовать | Пользователь выбрал Markdown. |

## 5. Основные сущности

- **Диалог Google:** серверная сущность, определяется надёжным thread/session ID либо подтверждённым URL/идентификатором. Название не является ID.
- **Реплика пользователя:** одно сообщение, отправленное пользователем внутри конкретной AI Mode-сессии.
- **Локальная организация:** папка, вложенность, цвет, порядок, UI-настройка.
- **Локальный индекс:** сохранённый текст диалога для поиска и Markdown-экспорта; не определяет наличие диалога в Google.
- **Не классифицированная строка:** видимый элемент Google, тип которого пока не доказан; не включается в список подтверждённых чатов.
