**Важное ограничение:** в v0.3.2 detectRows() принимает широкое множество кликабельных строк, а describeRow() допускает t:<title>. Это не финальный инструмент. Его нельзя переносить в следующий этап как одобренный алгоритм идентификации.

## 2. Автоматические проверки

Из папки Google-Search-AI-Chat-Organizer:

    node --check content.js
    npm test

CI: [GitHub Actions workflow](https://github.com/SarvasGD/Projects/actions/workflows/google-search-ai-chat-organizer.yml).

- Синтаксис и Manifest V3 проверяются автоматически.
- jsdom проверяет алгоритмы на синтетическом DOM.
- Реальные Google AI Mode DOM, полнота истории и изменение аккаунта CI не проверяет; нужна браузерная приёмка.

## 3. Диагностика

В v0.3.2 есть кнопка «Снимок DOM». Текущая реализация buildSnapshot() показывает ограниченную анонимизированную структуру заголовка, предков и нескольких первых строк.

Для следующего этапа её нужно расширить: фиксировать структуру сообщений внутри открытой сессии (теги/роли/атрибуты/геометрию/количество элементов), не копируя текст запросов и ответов. Текущий snapshot недостаточен для надёжного определения количества реплик.

## 4. Внешние инструменты и первичные источники

| Инструмент / источник | Подтверждённая возможность | Использование в проекте |
|---|---|---|
| [Google AI Mode history](https://support.google.com/websearch/answer/16011537) | Google документирует просмотр и удаление отдельных AI Mode searches через штатное меню More → Delete. | Источник для сценария серверного удаления. Не автоматизировать, пока идентичность строки не подтверждена. |
| [Google Search Services History](https://support.google.com/websearch/answer/17024959) | История может содержать поисковые запросы и Generative AI responses AI Mode; включает activity across Google Search services. | Основа понимания новых одиночных элементов истории и фильтрации в органайзере. |
| [LLMnesia — Google AI Mode History](https://www.llmnesia.com/blog/google-ai-mode-history) | Импорт доступных AI Mode conversations, Resume import, retry медленных/частичных чатов; хранение текста локально. | Референс для импорта, прогресса, повторных попыток и полнотекстового индекса. Не готовый код папочного органайзера. |
| chrome.storage.local | Локальное хранение папок, настроек и кэшированного текста. | Для пользовательской организации и локального индекса; не использовать как независимый источник наличия диалогов. |
| MutationObserver + повторное сканирование DOM | Отслеживание динамических изменений интерфейса Google. | Запуск автоматической синхронизации после изменений страницы; необходима защита от циклов собственных DOM-изменений. |

## 5. Что не является готовым инструментом

- Парсинг строки только по title.
- Счётчик сообщений, выводимый из числа DOM-кнопок истории.
- Массовое удаление по совпадению названий.
- Автоматическое слияние записей с одинаковым q или названием.
- Утверждение, что прохождение CI доказывает реальную совместимость с Google.
