# HDMS — документация проекта

**Актуальность:** 16 ноября 2026  
**Основной код MVP:** ../hdms-mvp/

## С чего начать

- START_HERE.md — актуальная точка входа и порядок чтения.
- 01_vision.md — видение и позиционирование.
- 02_feature_list.md — исходный фиче-лист и статус текущей реализации.
- 03_competitor_analysis.md — анализ конкурентов, UX-референсы и что исследовать.
- 04_tech_spec.md — фактическая архитектура и техническая спецификация.
- 05_task_pack.md — первоначальный пакет задач; исторический план, не текущий backlog.
- 06_monetization.md — коммерческая гипотеза, требует отдельной актуализации перед запуском.
- 07_rules_and_approximations.md — текущие игровые механики и ограничения.
- 08_mcp_workflow.md — историческая заметка о процессе исследования и разработки.
- 09_roadmap.md — текущий roadmap и активные P0-задачи.
- USER_GUIDE.md — инструкция по использованию локального MVP.
- REVERSE_ENGINEERING_PLAN.md — процесс исследования UI конкурентов, игровых правил и нескольких winlines.
- CHANGELOG.md — история актуализации документации.

## Источник истины

Для фактического состояния кода использовать HDMS/hdms-mvp/ и 04_tech_spec.md, а не первоначальные сроки и архитектурные схемы из концептуальных документов.

Отдельные файлы в этом каталоге — редактируемые источники. HDMS-Docs.md является историческим композитным снимком первой редакции и не должен редактироваться как параллельная копия всех документов.

## Статусы

- **Implemented** — функция есть в исходниках.
- **Verified** — есть тест/демонстрация пользовательского поведения.
- **Partial** — есть только часть ожидаемого поведения.
- **Planned** — ещё не реализовано.
- **Blocked** — обнаружена проблема, мешающая сценарию.
