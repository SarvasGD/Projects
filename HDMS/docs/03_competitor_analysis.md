## Итоговый вывод

1. По базовым функциям HDMS не уступает конкурентам.
2. По визуальному конструктору — конкурирует с FindStone и Firestone.
3. **По симуляции matchup (winrate, ход, HP) — единственный.** Это уникальное торговое предложение.
4. По winlines — единственный, кто генерирует их из симуляции, а не из реальных игр.
5. **По быстрому циклу «правка → тест → дельта winrate» — единственный.** Killer-фича.
6. По overlay и реальной статистике — проигрывает, но это не конкуренция, а дополнение.
7. По мобильности (PWA) — выигрывает у HDT/Firestone (десктоп), проигрывает FindStone (нативный iOS).
8. По цене — может конкурировать с бесплатными через Free+Premium ($3–5/мес).

## Что копировать у самой Hearthstone

**Не нужно.** Другие сервисы (HSReplay, Firestone, FindStone) уже скопировали UI-паттерны Hearthstone. Достаточно взять их интерфейсы — это быстрее и юридически безопаснее.

**Изображения карт** — легально через HearthstoneJSON (URL картинок в объекте карты). Звуки и анимации не копировать (юридический риск, для калькулятора не нужны).
