# 01 — Видение продукта

## Что такое HDMS

**HDMS (Hearthstone Deck Matchup Simulator)** — это калькулятор сравнения колод Hearthstone в формате Стандарт. Пользователь загружает две колоды по deck-коду, запускает Monte Carlo-симуляцию, и получает:

- Winrate колоды A против колоды B;
- Распределение ходов победы (гистограмма);
- Средний HP на победе;
- Winlines — 3–5 репрезентативных партий с полным логом по ходам.

## Ключевая идея

Игрок может **скрытно и безопасно** проверять гипотезы колод до выкатки в игру. Это **проверка гипотез**, а не сбор статистики реальных игр (как у HSReplay) и не запись своих матчей (как у HDT).

## Позиционирование

| Аспект ↕▾ | Значение ↕▾ |
|---|---|
| −Формат | Стандарт (Вольный — позже, Итерация 3) |
| −Аудитория | Игроки, которые хотят тестировать колоды до игры |
| −Конкуренты | HSReplay, HDT, Firestone, FindStone, hearthstone-oracle |
| −Отличие от конкурентов | **Единственный** сервис с симуляцией matchup A vs B |
| −Юридический статус | Не нарушает ToS Blizzard (не бот, не автоматизация игры) |
⚙

## Цели

### Продуктовые

- MVP с рабочим matchup-симулятором — за 2–2.5 недели.
- Полноценный продукт с конструктором и быстрым циклом тестов — за 4–5 недель.
- Все архетипы (aggro/tempo/midrange/control/combo) — за 7 недель.

### Коммерческие

- **$1000 в первый месяц после выкатки.**
- Модель: разовый Lifetime Deal для первых пользователей + подписка для новых.
- Площадка: PWA + собственный сайт через Paddle (Merchant of Record).

## Принципиальные ограничения

- Симуляция **model-based**, не полноценный движок правил Blizzard.
- Точные механики: мана, добор, усталость, бой, Провокация, Божественный щит, Рывок, Натиск, Неистовство ветра, Боевые кличи, Предсмертные хрипы, Комбо (как триггер), Перегрузка, зарядка силы героя (1–10 уровней), Rewind, бафы/дебафы, броня, лечение.
- Упрощённые механики: секреты, Discover, копирование карт.
- Полный стек приоритетов Blizzard — **не реализуем**.
