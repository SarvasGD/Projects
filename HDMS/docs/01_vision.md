# 01 — Видение продукта

## Что такое HDMS

**HDMS (Hearthstone Deck Matchup Simulator)** — это калькулятор сравнения колод Hearthstone в формате Стандарт. Пользователь загружает две колоды по deck-коду, запускает Monte Carlo-симуляцию, и получает:

- Winrate колоды A против колоды B;
- Распределение ходов победы (гистограмма);
- Средний HP на победе;
- Winlines — 3–5 репрезентативных партий с полным логом по ходам.

## Ключевая идея

Игрок может **скрытно и безопасно** проверять гипотезы колод до выкатки в игру. Это **проверка гипотез**, а не сбор статистики реальных игр (как у HSReplay) и не запись своих матчей (как у HDT).

## Позиционирование

| Аспект ↕▾ | Значение ↕▾ |

| −Формат | Стандарт (Вольный — позже, Итерация 3) |

| −Конкуренты | HSReplay, HDT, Firestone, FindStone, hearthstone-oracle |

## Цели

### Продуктовые

- MVP с рабочим matchup-симулятором — за 2–2.5 недели.
- Полноценный продукт с конструктором и быстрым циклом тестов — за 4–5 недель.
- Все архетипы (aggro/tempo/midrange/control/combo) — за 7 недель.

### Коммерческие

- **$1000 в первый месяц после выкатки.**
- Модель: разовый Lifetime Deal для первых пользователей + подписка для новых.
- Площадка: PWA + собственный сайт через Paddle (Merchant of Record).

## Принципиальные ограничения

- Симуляция **model-based**, не полноценный движок правил Blizzard.
- Точные механики: мана, добор, усталость, бой, Провокация, Божественный щит, Рывок, Натиск, Неистовство ветра, Боевые кличи, Предсмертные хрипы, Комбо (как триггер), Перегрузка, зарядка силы героя (1–10 уровней), Rewind, бафы/дебафы, броня, лечение.
- Упрощённые механики: секреты, Discover, копирование карт.
- Полный стек приоритетов Blizzard — **не реализуем**.

## Уточнение аналитической модели: несколько линий победы

Целевая аналитика HDMS должна поддерживать несколько самостоятельных winlines внутри одной колоды. Одной стратегической идеи может соответствовать несколько различных последовательностей и подлиний. В партии могут проявляться одна линия, её вариант или смешанная линия, объединяющая несколько пакетов карт.

Например, исследуемая Rogue Dragon-Charge может выигрывать через пакет зарядки/Imbue, через Dragon-пакет либо через их сочетание. Это рабочая гипотеза для проверки, а не заранее установленный факт о силе или числе линий этой деки.

**Не вводить универсальный критерий «хорошая колода обязана иметь больше двух winlines».** Проверять самостоятельность каждой линии по реальным событиям партий, победам без ключевых событий альтернативного пакета, устойчивости против разных противников и ablation-тестам.

Не смешивать:
- **Goldfish** — тест сборки собственного плана колоды без полноценного взаимодействия оппонента;
- **Matchup Winlines** — успешные последовательности действий в смоделированных матчах против конкретной колоды;
- **Strategy family** — общую идею/план;
- **Composite line** — смешанную реализацию нескольких линий.

В текущем MVP такая аналитика ещё не реализована. Текущее поле WinPath — грубая эвристическая категория. Подробная постановка — в REVERSE_ENGINEERING_PLAN.md и 09_roadmap.md.
