# 02 — Фиче-лист HDMS

**Легенда:** ✅ входит в этап; ➖ не входит.
**Ключевой принцип:** matchup-симулятор — это ядро Прототипа, а не что-то после MVP. Без него продукт не имеет смысла.

> **Актуальный статус на 16.11.2026:** историческая матрица ниже сохраняет первоначальные этапы и планируемый объём, но не означает, что все пункты реализованы. Текущий статус сверяй с таблицей в начале Roadmap: [09_roadmap.md](./09_roadmap.md). В частности, Winlines пока представлены тремя выбранными партиями с обрезанным журналом; несколько независимых линий, полный replay и отдельный Goldfish анализ не реализованы.

## Что НЕ входит никогда (out of scope)

- Поля Сражений, Арена, Дуэли.
- Полный стек приоритетов Blizzard.
- Графическое поле, анимации боя, игра против человека.
- Официальный API Blizzard (не существует).
- Бот, играющий в Hearthstone (отдельный продукт, не HDMS).

## Принцип Парето

- **20% фич дают 80% ценности:** #1, #2 — импорт + matchup. Это ядро.
- **Следующие 20% дают ещё 15%:** #3–8 — сохранение, история, winlines, конструктор.
- **Остальные 60% дают 5%:** #9–18 — глубина и полировка.

Discover (#11) — на Итерации 2, потому что без быстрого цикла «правка → тест» он не даёт пользователю пользы.
