## 2. Журнал исследованных материалов

| Evidence ID | Путь / URL / раздел | Тип | Commit SHA / версия | Строки / диапазон | Что проверялось | Результат наблюдения | Связанные правила / тесты |
|---|---|---|---|---|---|---|---|

Тип материала: README / документация / тест / schema / исходный модуль / UI-поведение / пример данных / release notes.

Указывай и материалы, которые оказались нерелевантными или не подтвердили гипотезу, если это важно для оценки полноты.

## 3. Карточка доказательства

Для каждого существенного утверждения создай запись:
- Evidence ID:
- Утверждение спецификации:
- Источник и точный путь:
- Commit SHA / tag:
- Строки:
- Permalink:
- Что именно доказывает источник:
- Что он не доказывает:
- Статус: Confirmed / Inferred / Hypothesis / Unknown.
- Связанные разделы спецификации и Test ID.

Не цитируй исходный код в функциональной спецификации. В evidence register достаточно точно указать первичный источник и смысл доказательства; при необходимости приведи только короткое неподлежащее охране имя сущности или общепринятый термин.

## 4. Качество доказательств

- **A — первичное и прямое:** тест, исходный файл, схема, релизная заметка или наблюдаемое поведение назначенного донора.
- **B — первичное, но косвенное:** документация, пример или комментарий, из которого следует вывод.
- **C — слабое/неполное:** косвенный поисковый фрагмент, неполный код-контекст, неподтверждённое описание.
- **U — отсутствует:** нужное поведение не подтверждено.

Для критического правила стремись к A. Доказательства C/U не позволяют пометить правило Confirmed.

## 9. Самопроверка перед передачей

- [ ] Зафиксирован commit SHA и дата.
- [ ] Указаны конкретные пути и строки, а не только ссылки на главную страницу репозитория.
- [ ] Существенные утверждения спецификации имеют Evidence ID.
- [ ] Открыты релевантные исходники и тесты, а не только README.
- [ ] Проверены отрицательные случаи и альтернативные сценарии.
- [ ] Неподтверждённое помечено Unknown / Hypothesis.
- [ ] Не использовались другие доноры для заполнения пробелов.
- [ ] В документ не перенесены исходные фрагменты и уникальные внутренние структуры.
- [ ] Ограничения исследования перечислены честно.
