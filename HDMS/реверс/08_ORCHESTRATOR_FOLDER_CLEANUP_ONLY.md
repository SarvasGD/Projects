**Запрет:** не проводить анализ, ревью или деконструкцию материалов.

## 1. Границы задания

Сейчас нужно выполнить исключительно файловую уборку папки HDMS/реверс/ и подготовить удобную передачу следующей итерации реверса Qwen Desktop Agent.

**Не читай содержимое и не анализируй:**
- независимый отчёт ChatGPT в HDMS/контроль/;
- исходную Function Spec Iteration 1;
- исходный Evidence Register Iteration 1;
- два результата Qwen Iteration 2;
- новую корректирующую постановку реверсу;
- код Firestone или код HDMS;
- документы продукта и Roadmap.

Не выполняй контроль качества, не перепроверяй выводы, не строй собственные гипотезы и не составляй предварительное заключение по реверсу. Для этой задачи достаточно имён, путей, размеров и Git blob SHA из GitHub Contents API.

Единственный документ, который нужно прочитать по содержанию, — это настоящее ТЗ. Если какая-либо операция требует чтения перечисленных выше материалов, остановись на этой операции, оставь файлы нетронутыми и сообщи о препятствии. Не пытайся «помочь» предварительной аналитикой.

## 7. Порядок GitHub-операций

1. Получи свежий HEAD main и зафиксируй его в отчёте.
2. Проверь по GitHub Contents API наличие файлов по точным путям и их blob SHA. Не скачивай их содержимое.
3. Убедись, что в handoff-папке присутствуют ровно пять перечисленных файлов. Если их число или имена отличаются — не исправляй содержимое, зафиксируй расхождение.
4. Создай архивный каталог и перемести три файла из раздела 4.
5. Удали два невыданных файла из раздела 5.
6. Повторно проверь дерево папок и blob SHA перемещённых документов.
7. Проверь, что канонические 01–04 и пять файлов handoff остались нетронутыми.
8. Закоммить только перечисленные файловые операции. Никакого force push.

Если GitHub API не позволяет сделать move напрямую, используй безопасный сценарий copy-to-new-path с тем же содержимым и SHA blob, проверка созданного файла, затем удаление старого пути. Не перезаписывай неожиданный существующий файл.

## 8. Что делать после уборки

После завершения файловой организации **остановись и жди отдельного задания**.

Следующая последовательность проекта:
1. Владелец передаёт ровно пять документов из handoff-папки Qwen Desktop Agent.
2. Qwen выполняет корректирующую деконструкцию и выдаёт два полных результата.
3. Только после появления этих двух готовых документов Оркестратор получает новую задачу: проверка результата, совместная организация/архивация, чистка папки и обновление пайплайна при необходимости.

До этого момента запрещено:
- читать независимый отчёт ChatGPT;
- читать или оценивать любые результаты реверса;
- переносить сырые материалы из других папок;
- создавать новые спецификации, отчёты или предварительные выводы;
- начинать вторую часть работы заранее.
