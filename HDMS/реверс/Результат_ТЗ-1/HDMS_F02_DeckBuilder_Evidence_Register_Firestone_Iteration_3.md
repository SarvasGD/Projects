## 3. Карточки доказательств (существенные утверждения Итерации 3)

### Сквозная цепь коллекции и пыли
**Утверждение:** Поток наборов инициализируется пустым списком, что создаёт транзитивную пустую эмиссию плоского списка карточек до построения полного каталога.
- Источник: менеджер наборов, строки 27–41 (инициализация), 32–40 (подписка с окном агрегации).
- Доказывает: начальное значение потока и отложенное построение каталога.
- Не доказывает: точное начальное значение источника коллекции пользователя (файл не загружен в этом сеансе; не влияет на вывод из-за нормализации).
- Статус: Confirmed.

**Утверждение:** Полный каталог карточек строится по всем наборам; отсутствующим в коллекции карточкам присваивается нулевое владение по всем видам копий. Это не сырой список карт пользователя.
- Источник: менеджер наборов, строки 43–77.
- Доказывает: механизм построения каталога и нулевых счётчиков.
- Статус: Confirmed.

**Утверждение:** Конструктор разворачивает наборы в единый плоский список карточек с собственной начальной пустой эмиссией и передаёт его в компонент списка колоды.
- Источник: компонент рабочей области, строки 291–297 (разворот), шаблон 68–76 (передача).
- Доказывает: промежуточное звено между менеджером наборов и списком колоды.
- Статус: Confirmed.

**Утверждение:** Компонент списка колоды нормализует пустой/отсутствующий вход в неизвестное состояние, при котором все карты считаются обеспеченными; непустой вход превращается в словарь владения.
- Источник: статический список колоды, строки 91–115.
- Доказывает: ветвление нормализации входа.
- Статус: Confirmed.

**Утверждение:** Маркер нехватки агрегирует владение по всем альтернативным версиям карты и сравнивает с требуемым количеством; при неизвестном состоянии все карты считаются обеспеченными.
- Источник: статический список колоды, строки 183–213; утилиты коллекции, строки 8–32.
- Доказывает: алгоритм маркера и агрегацию по версиям.
- Не доказывает: согласованность с расчётом пыли (там другой алгоритм).
- Статус: Confirmed.

**Утверждение:** Расчёт недостающей пыли независим от маркера: владение берётся по точному идентификатору карты, агрегация по альтернативным версиям не применяется; недостающие копии умножаются на стоимость создания по редкости.
- Источник: компонент рабочей области, строки 431–446; таблица стоимости — утилиты игровой логики, строки 800–811.
- Доказывает: алгоритм пыли и таблицу стоимости (40/100/400/1600).
- Не доказывает: премиальный путь (не используется в этом алгоритме).
- Статус: Confirmed.

**Утверждение (исправление прежней ошибки):** Для непустой колоды с известной редкостью в состоянии пустого точного-идентикатора потока пыль не равна нулю — она равна полной стоимости недостающих копий. Прежнее утверждение «пыль = 0» было неверно.
- Основание: компонент рабочей области, строки 431–446 (поиск по точному идентификатору в пустом/нулевом списке возвращает 0 владения → недостающие = требуемое).
- Статус: Confirmed.
