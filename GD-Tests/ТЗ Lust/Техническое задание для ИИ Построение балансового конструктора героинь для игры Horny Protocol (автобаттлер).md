# Техническое задание для ИИ: Построение балансового конструктора героинь для игры Horny Protocol (автобаттлер)

**Цель:** Создать структуру Google Sheets, позволяющую геймдизайнеру итеративно балансировать характеристики героинь через изменяемые переменные и автоматически пересчитываемые метрики (Power Score, EHP, ED).

**Контекст:** Horny Protocol - adult-автобаттлер (формат Ludus). Героини сражаются автоматически, имеют роли (Танк, Дамагер, Саппорт) и редкость (Обычная, Редкая, Эпическая, Легендарная). Необходимо предоставить конструктор для тестового задания (Блок 3).

**Требования к итоговому артефакту:**
- Набор готовых для копирования блоков (markdown с табуляциями), которые можно вставить в Google Sheets на отдельные вкладки.
- Все формулы должны быть работоспособны после вставки.
- Явно разделены константы, переменные и расчётные поля.
- Присутствует инструмент сравнения героинь для выявления дисбаланса.

**Структура Google Sheets (4 вкладки):**

1. **Вкладка «Множители»**  
   - Столбцы: Редкость, Множитель  
   - Константы множителей редкости: Обычная=1.0, Редкая=1.3, Эпическая=1.7, Легендарная=2.2  
   - Обоснование: взяты из жанрового анализа, отражают масштабирование силы.

2. **Вкладка «Веса»**  
   - Столбцы: Характеристика, Вес  
   - Константы весов для формулы Power Score: Атака=1.0, Здоровье=0.01, Защита=0.8, Скорость=5.0, Крит. шанс=50, Крит. урон=20.  
   - Обоснование: типичные коэффициенты для автобаттлеров, отражают вклад каждого стата в боевую эффективность.

3. **Вкладка «Диапазоны»**  
   - Столбцы: Редкость, Мин PS, Макс PS  
   - Целевые интервалы Power Score по редкостям: Обычная 2000-3500, Редкая 3500-6500, Эпическая 6500-10000, Легендарная 10000-15000.  
   - Интервалы подобраны так, чтобы легендарный герой был примерно в 2.2 раза сильнее обычного (соответствует множителю).

4. **Вкладка «Героини»** (основной конструктор)  
   - Заголовки столбцов: Имя, Роль, Редкость, Элемент, Атака, Здоровье, Защита, Скорость, Крит. шанс, Крит. урон, Множитель редкости, Power Score, EHP, ED, Мин PS, Макс PS, Валидация.  
   - Данные героинь (5 строк) – это **переменные**, которые можно изменять. Начальные сбалансированные значения должны быть подобраны так, чтобы PS находился в середине диапазона для своей редкости, а EHP/PS и ED/PS соответствовали роли (у танка выше EHP/PS, у дамагера выше ED/PS).  
   - Формулы:  
     * Множитель редкости: `=VLOOKUP(C2, Множители!A:B, 2, FALSE)`  
     * Power Score: `=(E2*VLOOKUP("Атака", Весы!A:B, 2, FALSE) + F2*VLOOKUP("Здоровье", Весы!A:B, 2, FALSE) + G2*VLOOKUP("Защита", Весы!A:B, 2, FALSE) + H2*VLOOKUP("Скорость", Весы!A:B, 2, FALSE) + I2*VLOOKUP("Крит. шанс", Весы!A:B, 2, FALSE) + J2*VLOOKUP("Крит. урон", Весы!A:B, 2, FALSE)) * K2`  
     * EHP (Effective Health): `=F2*(1+G2/10000)` (упрощённая модель: здоровье, усиленное защитой)  
     * ED (Effective Damage): `=E2*(1+(I2/100)*(J2/100))` (средний урон с учётом критов)  
     * Мин PS: `=VLOOKUP(C2, Диапазоны!A:C, 2, FALSE)`  
     * Макс PS: `=VLOOKUP(C2, Диапазоны!A:C, 3, FALSE)`  
     * Валидация: `=IF(AND(L2>=O2, L2<=P2), "OK", "ВНЕ ДИАПАЗОНА")`  
   - Для наглядности можно настроить условное форматирование по столбцу «Валидация».

5. **Вкладка «Сравнение»** (инструмент тестирования)  
   - Столбцы: Имя, Роль, Редкость, Power Score, EHP, ED, EHP/PS, ED/PS.  
   - Строки подтягивают данные с вкладки «Героини» через прямые ссылки (например, `=Героини!A2`).  
   - EHP/PS и ED/PS показывают, сколько единиц живучести/урона приходится на единицу силы. Если у двух героинь с одинаковым PS сильно различаются эти показатели, формула PS требует корректировки весов.

**Дополнительные указания:**
- Все строки таблиц разделены табуляцией, чтобы после копирования блока и вставки в Google Sheets данные корректно разнеслись по столбцам.
- Использовать только короткое тире «-», не использовать длинное тире.
- Привести полностью заполненные блоки для каждой вкладки в виде markdown-кода (обёрнутого в тройные обратные кавычки) с реальными данными и формулами.

**Результат:** ИИ должна предоставить четыре блока текста, готовых для копирования в Google Sheets, которые в совокупности образуют полноценный балансовый конструктор.
